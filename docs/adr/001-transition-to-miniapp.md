# 001. Переход к маркетинговой платформе на базе Telegram Mini App

## Контекст
Исходный проект *MarketFlow* предназначался для обработки биржевых данных и торговых стратегий. В рамках нового видения продукт трансформируется в мульти‑тенантный SaaS для маркетинговой аналитики, доступный через Telegram Mini App.

## Решение
- Перейти от биржевой тематики к аналитике рекламных каналов и пользовательских событий.
- Использовать архитектуру «backend + Telegram Mini App», где бот открывает веб‑приложение на React/Vite.
- Обеспечить мульти‑тенантность, авторизацию через Telegram и изоляцию данных на уровне БД (RLS).
- Хранить события, касания и атрибуцию в PostgreSQL с миграциями Liquibase.

## Последствия
- Потребуется переработка схемы БД, API, модулей и инфраструктуры.
- Все новые ключевые решения фиксируются отдельными ADR и сводятся в файл `MIGRATION.md`.
